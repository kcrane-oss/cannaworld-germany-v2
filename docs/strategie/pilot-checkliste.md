## A. Partner-Outreach (vor eigener Akkreditierung)

### A.1 OneCert — Agrar-/GACP-Layer
- [ ] Richtige Entity identifizieren (regionale OneCert-Niederlassung mit Asien-Auditoren).
- [ ] Scope abklären: Thai GACP, EMA-GACP, Bio, **Gruppen-/Cluster-Zertifizierung** (Weg B).
- [ ] Durchlaufzeit + Kosten pro Farm **und** pro Gruppen-Audit erfragen.
- [ ] MoU senden (`vorlagen/mou-zertifizierungspartner-vorlage.md`, Variante OneCert / Abschnitt 3).
- [ ] Datenfluss klären: in welchem Format kommen Zertifikate/Berichte ins Dossier?

### A.2 TÜV (SÜD / Rheinland / NORD) — Pharma-/GMP-Layer
- [ ] Geschäftsbereich Pharma/GMP-Audit + Standort mit Thailand-Reichweite finden.
- [ ] Scope: **GMP-Gap-/Readiness-Audit des Hub-Werks**, Werks-Qualifizierung, EU-GMP-Begleitung.
- [ ] Gap-Assessment des Ziel-Hubs als ersten konkreten Auftrag anfragen.
- [ ] MoU senden (gleiche Vorlage, Variante TÜV / Abschnitt 4).

### A.3 EU-GMP-Importeur mit QP (Weg C — Sofort-Marktzugang)
- [ ] Deutsche MIA-/QP-Inhaber mit Cannabis-Erfahrung listen.
- [ ] Bereitschaft zur **Chargenfreigabe für Fremd-Supply** + Re-Testing-Konditionen klären.
- [ ] Übergangs-/Exit-Klausel: gilt, bis CannaWorld eigene Erlaubnis hat.

## B. Hub-Werk auswählen (Weg A — das Rückgrat)
- [ ] 2–3 Kandidaten-Werke in TH mit Verarbeitungs-/QC-Kapazität.
- [ ] GMP-Ist-Stand: keiner / Gap-assessed / in progress / EU-GMP-zertifiziert?
- [ ] Bestrahlungs-/Sterilisations-Kapazität + EU-Akzeptanz prüfen.
- [ ] Kapazitätsabgleich: trägt ein Hub die geplante Farm-Anzahl?
- [ ] Single-Point-of-Failure notieren → mittelfristig zweiter Hub.

## C. Lighthouse-Farmen (1–2, Proof + Blueprint)
- [ ] Kandidaten nach Lage, bestehender Doku-Disziplin, Kooperationswille wählen.
- [ ] Farm-MoU (`vorlagen/mou-farm-onboarding-vorlage.md`), zweisprachig TH/EN.
- [ ] Auf **Thai GACP** über OneCert führen (Tier 1 → Tier 2).
- [ ] **SOP-/Trainings-/Dossier-Pack** dokumentieren → exakt dieser Pack wird repliziert (Weg E).
- [ ] An Hub koppeln (Tier 3), erste Charge durch Fremd-QP freigeben.

## D. Regulatorische Tür-Voraussetzungen (hart — ohne diese kein Export)
- [ ] **Thailand-Export:** Thai FDA / ONCB Export-Permit-Pfad + Voraussetzungen geklärt.
- [ ] **DE-Import:** BfArM / Bundesopiumstelle Einfuhrgenehmigung (MedCanG-Regime seit 2024).
- [ ] Single-Convention-Schätzmengen / Kontingente berücksichtigt.
- [ ] THC-Einstufung + Dokumentationskette „Saatgut → Charge" lückenlos.
- [ ] QP-Re-Testing-/Identitäts-Anforderungen mit Importeur abgestimmt.

## E. Compliance-/Marketing-Leitplanken (laufend)
- [ ] B2B-only; keine Verbraucher-, Heil-, Wirkversprechen, keine Sortenwerbung.
- [ ] Außendarstellung: *„qualifiziert in Partnerschaft mit OneCert/TÜV"* — nicht „zertifiziert durch uns".
- [ ] Standard-Transparenz: klar kommunizieren, wer welche Schicht (GACP vs. GMP) trägt.
- [ ] Antikorruption / Exportkontrolle / Sanktionsrecht bei TH-Geschäft beachten.

## F. Pilot-Erfolgskriterien (definieren, bevor man startet)
- [ ] X Farmen auf Tier 2 in Y Monaten.
- [ ] Hub-Gap-Score ≤ Schwelle Z / EU-GMP-Pfad terminiert.
- [ ] Erste konforme Charge mit gültigem Export- + Einfuhr-Permit in DE freigegeben.
- [ ] Replizierbarer SOP-Pack steht (Voraussetzung für Skalierung Weg B/E).
